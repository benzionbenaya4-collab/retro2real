# מרטרו לרגיל (Retro2Real)

אבא נשאב לתוך משחק רטרו ועובר דרך כל הדורות של עולם המשחקים: 8 ביט, 16 ביט, 32 ביט והיום.

- `index.html` – דף המשחק (בינתיים: בקרוב).
- `assets/sprites` – ספרייטים ואריחים של 8 ו-16 ביט (PNG + JSON אנימציות).
- `assets/3d` – מודלים בתלת־ממד (GLB): מודרני ו-32 ביט.

המשחק בפיתוח.
