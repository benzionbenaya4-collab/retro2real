# מרטרו לרגיל – המשחק (גרסה ראשונה שאפשר לשחק בה)

פותחים את `index.html` דרך שרת מקומי מתיקיית `projects/retro2real/` (למשל `python3 -m http.server`), ונכנסים ל-`/game/`.
אין build. three.js 0.160 נטען מ-jsdelivr דרך importmap.

## עולמות
1. **עמק 8 ביט** – top-down בארבעה גוונים ירוקים. ה-void מתפשט, תולעים יוצאות ממנו, ושברי קוד מחזירים אריחים. 3 גלים.
2. **ממלכת 16 ביט** – אותו מנוע. בסוף: הסוס הטרויאני כמיני-בוס, שמסתער ומוציא תולעים.
3. **32 ביט (three.js)** – דן low-poly עם רִיג glbchar, מצלמה מאחורי הכתף, רינדור ברזולוציה נמוכה + NearestFilter, שליטת טנק.
4. **הקרב האחרון** – ההאקר קופץ 8 → 16 → 32 → מודרני. בתחילת השלב המודרני פיקסי משדרג את החרב ל**חרב האינסוף**.

פיקסי: מד טוקנים. הכפתור "פיקסי" (או P) עושה סריקה (מפה, סימון אויבים ושברים) ועולה 30 טוקנים. באמצע קרב נגמרים לו הטוקנים 😅, ובסוף הקרב הם חוזרים.

## שליטה
- מחשב: חצים/WASD לתזוזה, רווח/J לחרב, P/X לפיקסי, Esc להשהיה.
- טלפון: ג'ויסטיק משמאל, A לחרב, כפתור "פיקסי".

## קבצים
- `js/main.js` – לולאה, מסכים, שמירה (localStorage עם try/catch).
- `js/world2d.js` – מנוע האריחים (מחולל מפה מ-seed, אויבים, void, שברים, מיני-בוס, זירת בוס).
- `js/world3d.js` – עולם 3 וזירות הבוס בתלת-ממד.
- `js/boss.js` – רצף העידנים של הבוס. `js/worlds.js` – כל ההגדרות.
- `js/vendor/` – עותקים של `strike3d/js/models/glbchar.js` ו-`strike3d/js/core/anim.js`.
- `screenshots/` – צילומי הבדיקה.

בדיקות לפיתוח: `window.__r2r.enterWorld(n)` קופץ לעולם.
